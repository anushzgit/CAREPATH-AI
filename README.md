# CAREPATH AI

CAREPATH AI is an AI-powered healthcare assistance website built using React, Vite, and Node.js.

## Features
- AI-powered symptom checker
- Health report explanation using Gemini AI
- Responsive web interface

## Tech Stack
- React
- Vite
- Node.js
- Express
- Google Gemini API

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create a `.env` file in the project root and add your Gemini API key:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

3. Start the development server using the project's configured scripts.

**Note:** Never share or commit your real API key. This project is intended for informational support and does not replace professional medical advice.
